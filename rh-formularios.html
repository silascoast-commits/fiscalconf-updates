Exportar Backup

Gera um arquivo .json com todos os dados do sistema (empresa, funcionários e histórico de formulários). Guarde esse arquivo em local seguro (e-mail, nuvem, pendrive) para não perder as informações caso troque de computador ou limpe os dados do navegador.

Importar Backup

Selecione um arquivo de backup (.json) gerado anteriormente para restaurar os dados. Você pode optar por substituir tudo que está cadastrado agora, ou mesclar com os dados atuais (adicionando o que não existir ainda).
