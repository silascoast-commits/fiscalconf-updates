PDF → XML eSocial (Admissão S-2200)

Envie a ficha de admissão em .pdf, confira os dados extraídos e gere o XML do evento evtAdmissao.
⚠️ A leitura do PDF acontece toda no seu navegador (nenhum arquivo é enviado a servidor algum), mas a primeira leitura carrega bibliotecas externas (pdf.js e Tesseract.js) — precisa de internet nesse momento. A extração é feita por OCR (o PDF é uma ficha "impressa"/exportada, sem texto selecionável) e usa os rótulos do modelo de ficha atual (ex.: "NOME COMPLETO", "CPF", "DATA DE ADMISSÃO") — ela pode falhar ou confundir campos se o layout do PDF for diferente do modelo testado. Campos preenchidos automaticamente ficam destacados em amarelo: confira e corrija todos antes de gerar o XML. Este XML segue as tags oficiais do evento S-2200 (evtAdmissao), mas é gerado sem assinatura digital: não é o envelope assinado que trafega no webservice do eSocial (isso exige certificado digital e envio por sistema homologado) — use-o para conferência ou importação em outro sistema. Campos como RG, CTPS, Título de Eleitor, CNH, PIS e nome dos pais não fazem parte do schema do evento de admissão, por isso ficam listados só como referência. As perguntas de Sim/Não da ficha (CNH, CTPS física, Filhos) são botões de alternância — o OCR lê o texto das duas opções mas não identifica qual está marcada, confira a resposta correta olhando o PDF original. Alguns sistemas de folha (import via XML) leem certos campos como número inteiro e travam se a tag vier vazia — por isso, campos numéricos deixados em branco (CNPJ, CEP, código do município, raça/cor, estado civil, grau de instrução, matrícula, data-base, CBO, horas semanais) saem no XML com um valor placeholder (normalmente "0", exceto raça/cor que usa "9 = não informado") em vez de tag vazia; a ferramenta avisa quais foram preenchidos assim para você corrigir antes de importar.
