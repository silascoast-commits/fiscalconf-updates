Visão Geral do Sistema
O que é, como abrir e como navegar

O Gestão Financeira é um sistema completo para controle financeiro de empresas, desenvolvido como um único arquivo HTML. Funciona diretamente no navegador, sem instalação, sem internet e sem servidor — basta abrir o arquivo.

Como Abrir o Sistema

1
Localize o arquivo gestao-financeira.html no seu computador.
2
Dê duplo clique no arquivo — ele abrirá automaticamente no seu navegador padrão (Chrome, Edge ou Firefox recomendados).
3
O sistema carrega instantaneamente. Não precisa de internet.
⚠
Os dados ficam salvos no localStorage do navegador. Não limpe o cache/histórico do navegador sem antes exportar um backup. Cada navegador/computador tem seu próprio localStorage.

Primeira Utilização — Configuração Inicial

Ao abrir o sistema pela primeira vez, recomendamos seguir esta sequência:

1
Clique em ⚙ Config e preencha os dados da empresa: nome, CNPJ e saldo inicial.
2
Acesse Categorias e crie as categorias que fazem sentido para o seu negócio (ou use as padrão).
3
Se utilizar contabilidade, acesse Plano de Contas e vincule categorias às contas contábeis.
4
Comece a lançar em Faturamento e Despesas.
5
Após a primeira semana de uso, faça o primeiro backup em Sistema → Backup.
ℹ
O sistema salva as alterações automaticamente — não existe botão "Salvar tudo". Cada operação (adicionar, editar, excluir) é persistida imediatamente no localStorage.

Parcelamento Automático NOVO v2

O campo "Parcelar em" divide o valor em N parcelas mensais automaticamente.

1
Preencha todos os campos normalmente, incluindo o Vencimento da primeira parcela.
2
Em Parcelar em, selecione o número de parcelas (2x, 3x, 4x, 6x, 10x, 12x ou 24x).
3
Clique em Salvar. O sistema cria automaticamente N despesas com a descrição "Nome da Despesa (1/N)", "(2/N)", etc., adicionando 1 mês a cada vencimento.
ℹ
O valor de cada parcela é o total dividido igualmente. Exemplo: R$ 1.200 em 6x = 6 lançamentos de R$ 200,00 cada.

Exemplo Prático de Parcelamento

Uma despesa de R$ 3.000,00 em 3x com vencimento em 05/07/2026 gera os seguintes lançamentos automáticos:

Software XYZ (2/3)2ª05/08/2026R$ 1.000
Software XYZ (3/3)3ª05/09/2026R$ 1.000

⚠
Ao excluir uma despesa parcelada, apenas a parcela selecionada é removida. As demais parcelas permanecem. Para cancelar todas as parcelas de uma vez, exclua cada uma individualmente ou altere o status para "Cancelado".

5
Clique em Atualizar para recalcular a tabela e o gráfico.

Importar Extrato OFX
Importar lançamentos bancários automaticamente

Importe extratos bancários no formato OFX (Open Financial Exchange) — compatível com a maioria dos bancos brasileiros (Bradesco, Itaú, Santander, BB, Caixa etc.).

Como Obter o Arquivo OFX no Banco

Cada banco tem um caminho diferente, geralmente: Internet Banking → Extrato → Exportar → Formato OFX.

Passo a Passo para Importar

1

Conciliação Bancária NOVO v2
Conferir lançamentos OFX com registros contábeis

A Conciliação Bancária é o processo de confirmar que os lançamentos importados do extrato bancário (OFX) correspondem aos lançamentos registrados no sistema (Faturamento e Despesas).

Por Que Conciliar?

  • Garantir que nenhum lançamento foi perdido ou duplicado
  • Identificar cobranças bancárias não reconhecidas
  • Confirmar que todos os recebimentos e pagamentos foram registrados
  • Fechar o mês com segurança contábil

Passo a Passo

1
Acesse Avançado → Conciliação.
2
Defina o período (De / Até) e o filtro (Não conciliados / Todos / Conciliados).
3
Clique em Filtrar para carregar os lançamentos.
4
Para cada lançamento conferido, clique em ✓ Conciliar.
5
Use 🤖 Auto-Conciliar para conciliar automaticamente lançamentos com valor exato (±1%) e data próxima (±3 dias) em relação aos lançamentos registrados.

Indicadores

KPIDescrição
OFX ImportadosTotal de lançamentos no extrato OFX
ConciliadosQuantos já foram verificados e confirmados
💡
Para desfazer uma conciliação, use o botão ↩ Desfazer que aparece nas linhas já conciliadas.

Critérios do Auto-Conciliar

O algoritmo de auto-conciliação busca correspondências entre lançamentos OFX e registros internos (Faturamento/Despesas) usando os seguintes critérios simultâneos:

CritérioTolerânciaMotivo
Valor±1%Acomoda pequenas diferenças de arredondamento bancário
Data±3 dias corridosLançamentos podem entrar no extrato com 1-2 dias de diferença
TipoExatoEntrada só concilia com entrada; saída com saída

Backup e Restauração
Proteger e recuperar os dados do sistema

Como os dados ficam no localStorage do navegador, é essencial fazer backup regularmente. O sistema alerta no Dashboard quando há mais de 7 dias sem backup.

🔴
Limpar o cache/cookies/histórico do navegador, desinstalar o navegador ou formatar o computador apaga todos os dados. Faça backup semanal ou após cada sessão importante.

Exportar Backup

Acesse Sistema → Backup / Restore e clique em um dos botões:

BotãoDescriçãoUso
⬇ Baixar Backup JSONExporta todos os dados em um único arquivo .jsonBackup principal — use este
⬇ Exportar Dados CSVExporta cada tabela em um arquivo .csv separadoAnálise em Excel ou migração
💡
O arquivo JSON de backup tem o nome backup_fiscalconf_AAAA-MM-DD.json. Guarde em nuvem (Google Drive, OneDrive) ou pen drive.

Restaurar Backup

1
Acesse Sistema → Backup / Restore.
2
Na seção "Restaurar Backup", clique em "Selecionar arquivo de backup (.json)".
3
Selecione o arquivo .json salvo anteriormente.
4
Clique em ↑ Restaurar Backup e confirme no diálogo.
5
O sistema carrega os dados e recarrega todos os módulos automaticamente.
⚠
Restaurar um backup substitui todos os dados atuais. Se você tem lançamentos novos que ainda não estão no backup, eles serão perdidos. Exporte um novo backup antes de restaurar.

Glossário
Termos utilizados no sistema
Aging
Análise de envelhecimento de títulos a receber ou pagar, agrupados por faixas de vencimento.
Balancete de Verificação
Relatório contábil que lista todas as contas com seus saldos devedores e credores, verificando o equilíbrio contábil.
Centro de Custo
Unidade organizacional (departamento) responsável por determinado grupo de despesas. Permite rastrear gastos por área.
Conciliação Bancária
Processo de comparar o extrato bancário com os lançamentos contábeis para garantir que estão em conformidade.
CP — Contas a Pagar
Obrigações financeiras da empresa com fornecedores e credores.
CR — Contas a Receber
Direitos da empresa sobre clientes que ainda não pagaram.
DRE
Demonstração do Resultado do Exercício — relatório que evidencia receitas, despesas e o resultado (lucro ou prejuízo) de um período.
Lançamento Recorrente
Modelo de lançamento que se repete com regularidade (mensal, semanal, anual). Ao gerar, cria o lançamento real e avança a data para a próxima ocorrência.
LocalStorage
Mecanismo de armazenamento do navegador que persiste os dados entre sessões, mas é isolado por navegador e computador.
OFX (Open Financial Exchange)
Formato padrão de arquivo de extrato bancário suportado pela maioria dos bancos brasileiros. Extensões: .ofx, .qfx, .ofc.
Parcela
Divisão de uma despesa em N pagamentos mensais. O sistema cria automaticamente os N lançamentos ao salvar com parcelamento ativado.
Plano de Contas
Estrutura hierárquica de contas contábeis que classifica todos os fatos econômicos da empresa, seguindo as normas NBC TG/CFC.
Saldo Acumulado
No Fluxo de Caixa, representa o saldo corrente após somar todas as entradas e subtrair todas as saídas desde o saldo inicial.
Status Automático
O sistema verifica automaticamente se um lançamento está "vencido" com base na data de vencimento vs. data atual, alterando o status de "pendente" para "vencido".
FITID (Financial Transaction ID)
Identificador único de cada lançamento dentro de um arquivo OFX, usado pelo sistema para detectar e evitar importações duplicadas.
DRE (Demonstração do Resultado do Exercício)
Relatório contábil-gerencial que evidencia as receitas, os custos, as despesas e o resultado (lucro ou prejuízo) de um exercício ou período.
NBC TG (Normas Brasileiras de Contabilidade — Técnicas Gerais)
Conjunto de normas emitidas pelo CFC (Conselho Federal de Contabilidade) que regulam a contabilidade no Brasil. O Plano de Contas padrão do sistema segue estas normas.
Prolabore
Remuneração paga aos sócios de uma empresa por seu trabalho administrativo. Diferente de lucros e dividendos, é uma despesa da empresa.
IOF (Imposto sobre Operações Financeiras)
Imposto federal incidente sobre operações financeiras como empréstimos, câmbio e seguros. Frequentemente aparece como lançamento bancário no extrato OFX.
Baixa
Operação de registro de recebimento (em CR) ou pagamento (em CP). Pode ser total (liquida o título) ou parcial (reduz o saldo pendente).
Simples Nacional
Regime tributário simplificado para micro e pequenas empresas brasileiras. O pagamento é feito via DAS (Documento de Arrecadação do Simples Nacional) mensalmente.

Boas Práticas de Gestão Financeira

💡
Check-list mensal recomendado:
  1. Verificar e gerar todos os lançamentos recorrentes vencidos
  2. Importar o extrato OFX do banco e conciliar as transações
  3. Lançar todas as despesas e faturas do mês
  4. Realizar as baixas de CR e CP com pagamentos confirmados
  5. Conferir o Fluxo de Caixa do mês
  6. Gerar o DRE Gerencial e revisar as margens
  7. Executar o backup JSON e salvar em nuvem
