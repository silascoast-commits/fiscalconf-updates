Capítulo 1

Visão Geral do Sistema

Introdução ao Gestão Financeira, abertura do arquivo e navegação principal

O Gestão Financeira é um sistema completo de controle financeiro pessoal e empresarial que roda inteiramente no navegador, sem necessidade de servidor, instalação ou conexão com a internet. Todos os dados são armazenados localmente no localStorage do navegador, garantindo privacidade total.

Como abrir o sistema

  1. Localize o arquivo gestao-financeira.html no seu computador.
  2. Dê duplo clique no arquivo ou arraste-o para a janela do navegador (Chrome, Edge ou Firefox recomendados).
  3. O sistema carregará automaticamente com os dados do último uso nesse navegador.
  4. Para uso contínuo, salve o arquivo em uma pasta de fácil acesso (ex.: Área de Trabalho).
O sistema não requer internet após ser aberto. Todos os dados ficam no navegador do computador atual. Ao abrir o arquivo em outro computador, os dados não estarão disponíveis — use o recurso de Backup (Capítulo 18) para transferi-los.

Interface principal

A tela é dividida em três áreas: o cabeçalho (header), a sidebar (menu lateral) e a área de conteúdo.

Header (Cabeçalho)

O cabeçalho exibe:

  • Ícone e nome do sistema — configuráveis em ⚙ Config
  • Nome da empresa — exibido ao lado do título
  • Data atual — atualizada automaticamente a cada abertura
  • Botão ⚙ Config — abre o painel de configurações do sistema
  • Botão 🔍 Busca — abre a busca global em todos os módulos

Sidebar (Menu lateral)

A sidebar contém todos os módulos do sistema. Clique em qualquer item para navegar. O módulo ativo fica destacado em azul. Em telas menores, a sidebar pode ser recolhida clicando no ícone de menu (☰).

Área de conteúdo

Ocupa a maior parte da tela e exibe o módulo selecionado na sidebar. Cada módulo possui seu próprio formulário de lançamento, filtros e tabela de registros.

Use a tecla Esc para fechar painéis flutuantes como a Busca Global e o modal de configurações.

Configurações

Personalização do sistema, dados da empresa e opções avançadas

As configurações permitem personalizar a identidade visual do sistema e os dados cadastrais da empresa. Para acessar, clique no botão ⚙ Config no canto superior direito do cabeçalho.

  5. Clique em Salvar Configurações para aplicar as alterações.
  6. Clique em Fechar ou pressione Esc para sair sem salvar.

Capítulo 4

Faturamento

Registro e gestão de receitas, notas fiscais e cobranças emitidas

O módulo de Faturamento registra todas as receitas da empresa: vendas, prestação de serviços, cobranças emitidas etc. Cada registro representa um documento ou nota fiscal emitida ao cliente.

Como registrar um faturamento

  1. Na sidebar, clique em 💵 Faturamento.
  2. No formulário superior, preencha os campos necessários.
  3. Selecione o Status (Pendente, Recebido ou Cancelado).
  4. Clique em Salvar para gravar o registro.
  5. Use Limpar para resetar o formulário sem salvar.

Capítulo 5

Despesas

Registro de custos, despesas operacionais e parcelamentos automáticos

O módulo de Despesas registra todos os gastos da empresa: contas fixas, despesas variáveis, compras, serviços contratados etc. Possui os mesmos campos do Faturamento com adição de Fornecedor, Centro de Custo e a opção de parcelamento automático.

Como registrar uma despesa

  1. Na sidebar, clique em 💸 Despesas.
  2. Preencha os campos do formulário. Fornecedor e Centro de Custo são exclusivos deste módulo.
  3. Para parcelar, selecione o número de parcelas no campo Parcelar em.
  4. Clique em Salvar. Se houve parcelamento, o sistema cria automaticamente N registros mensais.

Parcelamento automático

Ao selecionar um número de parcelas, o sistema divide o valor total e cria N registros mensais sequenciais. Exemplo: R$ 6.000 em 3x gera:

  • "Compra de equipamento (1/3)" — R$ 2.000 — vence em junho/2026
  • "Compra de equipamento (2/3)" — R$ 2.000 — vence em julho/2026
  • "Compra de equipamento (3/3)" — R$ 2.000 — vence em agosto/2026
Os registros de parcelas são independentes após criados. Você pode alterar o status de cada parcela individualmente conforme vai realizando os pagamentos.

Filtros da tabela

  • Busca — filtra por fornecedor, descrição ou número de documento
  • Status — Pendente, Pago, Cancelado
  • Categoria — filtra por categoria de despesa
  • Mês — filtra pelo mês de vencimento
Despesas com status Cancelado não entram no cálculo do Fluxo de Caixa nem nos Relatórios. Use Cancelado apenas quando a despesa for realmente anulada.

Controle de recebimentos parciais e totais de clientes

O módulo de Contas a Receber (CR) permite controlar recebimentos de clientes de forma detalhada, incluindo baixas parciais. Diferencia-se do Faturamento por permitir registrar o quanto já foi recebido de cada conta, facilitando o controle de pagamentos em aberto.

Como criar uma Conta a Receber

  2. Clique no botão + Nova CR.
  3. Preencha os campos do formulário (veja tabela abaixo).
  4. Clique em Salvar. O registro aparece na tabela com saldo calculado automaticamente.

Capítulo 8

Lançamentos Recorrentes NOVO

Automação de lançamentos periódicos de receitas e despesas fixas

Lançamentos Recorrentes permitem configurar despesas e receitas que se repetem periodicamente (aluguel, salários, assinaturas, mensalidades etc.) e gerar os registros automaticamente com um clique, sem redigitar os dados a cada período.

O que são lançamentos recorrentes?

São modelos de lançamento que o sistema usa para gerar automaticamente entradas nos módulos de Faturamento ou Despesas. Você cadastra o modelo uma vez e, quando chegar a data de próxima geração, basta clicar em ⚡ Gerar.

Como cadastrar um lançamento recorrente

  1. Na sidebar, clique em 🔄 Recorrentes.
  2. Clique em + Novo Recorrente.
  3. Preencha os campos do modelo (veja tabela abaixo).
  4. Clique em Salvar. O sistema calculará automaticamente a primeira data de próxima geração.

Análise do movimento financeiro realizado e projetado

Capítulo 10

Importar OFX

Importação de extratos bancários no formato OFX

O formato OFX (Open Financial Exchange) é um padrão universal de extrato bancário digital. A maioria dos bancos brasileiros permite baixar extratos neste formato. O módulo importa essas transações com seleção individual e categorização automática.

Como importar um arquivo OFX

  1. Na sidebar, clique em 🏦 Importar OFX.
  2. Arraste o arquivo .ofx para a área indicada, ou clique para abrir o seletor de arquivos.
  3. O sistema processará o arquivo e exibirá uma prévia de todas as transações encontradas.
  4. Revise cada transação: marque o checkbox das que deseja importar.
  5. Para cada transação, selecione ou edite a Categoria.
  6. Clique em Importar Selecionados para gravar as transações escolhidas.

Categorização automática por palavra-chave

O sistema aplica regras baseadas em palavras-chave na descrição da transação OFX. Exemplos:

  • Descrições contendo "ALUGUEL" → categoria "Aluguel"
  • Descrições contendo "SALARIO" ou "FOLHA" → categoria "Salários"

Capítulo 11

Conciliação Bancária NOVO

Cruzamento entre lançamentos do sistema e transações bancárias importadas

A Conciliação Bancária é o processo de verificar se os lançamentos registrados no sistema correspondem exatamente às transações do extrato bancário. Garante a integridade dos dados e detecta erros de lançamento ou transações não registradas.

Por que conciliar?

  • Garante que nenhuma transação bancária foi esquecida no sistema
  • Identifica lançamentos duplicados ou com valores incorretos
  • Mantém o saldo contábil alinhado com o saldo real do banco
  • Facilita auditorias e prestação de contas ao contador

Como realizar a conciliação

  1. Na sidebar, clique em ✅ Conciliação Bancária.
  2. Defina o período com os filtros De e Até.
  3. Em Mostrar, selecione "Não conciliados" para ver apenas os pendentes.
  4. Para conciliar manualmente, clique em ✓ Conciliar na linha da transação OFX.
  5. Para conciliação automática, clique em 🤖 Auto-Conciliar.

Auto-Conciliação inteligente

O botão 🤖 Auto-Conciliar cruza automaticamente as transações OFX com os lançamentos do sistema usando:

  • Valor — correspondência com tolerância de ±1% (para diferenças de centavos)
  • Data — correspondência com tolerância de ±3 dias (para atrasos de compensação bancária)

Capítulo 12

Extrato de Movimentações

Visão consolidada de todas as entradas e saídas com saldo acumulado

O Extrato de Movimentações exibe uma visão unificada de todos os lançamentos (faturamentos e despesas) em ordem cronológica, com cálculo de saldo acumulado por linha — similar a um extrato bancário digital.

Como acessar e usar o extrato

  1. Na sidebar, clique em 📋 Extrato.
  2. Defina o período com os filtros De e Até.
  3. Selecione o Tipo: Todos / Entradas / Saídas.
  4. Filtre por Categoria para ver apenas uma categoria específica.
  5. O extrato é exibido automaticamente com os dados filtrados.
  6. Clique em ⬇ CSV para exportar o extrato em formato de planilha.

Estrutura da tabela

Cada linha exibe: Data, Tipo (Entrada/Saída), Descrição, Categoria, Valor e Saldo Acumulado após aquele lançamento.

Use o extrato filtrado por categoria para analisar o padrão de gastos por área (ex.: quanto foi gasto em "Marketing" nos últimos 3 meses).
O botão ⬇ CSV exporta apenas os dados atualmente filtrados. Ajuste os filtros antes de exportar para obter o recorte desejado.

Relatórios

Análises gerenciais: DRE, Aging, Categorias, Centro de Custo e Balancete

O módulo de Relatórios oferece análises gerenciais aprofundadas. Cada relatório é selecionado por um chip (botão) na parte superior do módulo.

Como acessar

  1. Na sidebar, clique em 📑 Relatórios.
  2. Clique no chip do relatório desejado.
  3. Ajuste os filtros de período ou parâmetros específicos.
  4. O relatório é gerado automaticamente.

DRE Gerencial

Demonstração do Resultado do Exercício simplificada:

  • Receita Bruta — total de faturamentos recebidos no período
  • Despesas por Categoria — detalhamento de cada categoria de gasto
  • Resultado Operacional — receita menos despesas totais
  • Margem — resultado como percentual da receita bruta

Aging CR e Aging CP

Relatório de envelhecimento das contas, dividido em faixas de vencimento:

  • A vencer (futuros)
  • Vencido há 1–30 dias
  • Vencido há 31–60 dias
  • Vencido há 61–90 dias
  • Vencido há mais de 90 dias

Por Categoria

Totais de receitas e despesas agrupados por categoria, com participação percentual de cada uma no total. Útil para análise de estrutura de custos.

Centro de Custo

Despesas agrupadas por centro de custo, permitindo avaliar o custo de cada departamento ou área da empresa no período.

Balancete NOVO

Exibe as contas do Plano de Contas com movimentação a Débito, a Crédito e o Saldo resultante. Requer que as categorias estejam vinculadas às contas contábeis no módulo de Plano de Contas (Capítulo 16).

Para o Balancete funcionar corretamente, vincule as categorias às contas contábeis no Plano de Contas (Capítulo 16).
Exporte qualquer relatório para PDF usando o botão 🖨 Salvar como PDF para compartilhar com gestores ou contador.

Busca Global NOVO

Pesquisa unificada em todos os módulos do sistema

A Busca Global permite encontrar qualquer lançamento em qualquer módulo a partir de um único campo de pesquisa. Os resultados são agrupados por módulo para facilitar a identificação.

Como usar a Busca Global

  1. Clique no botão 🔍 Busca no cabeçalho do sistema.
  2. Um painel flutuante se abrirá no centro da tela.
  3. Digite pelo menos 2 caracteres para iniciar a busca (resultados aparecem em tempo real).
  4. Os resultados são agrupados por módulo: Faturamento, Despesas, CR, CP, Extrato.
  5. Clique em qualquer resultado para navegar diretamente ao módulo com o registro destacado.
  6. Pressione Esc ou clique fora do painel para fechar.

Capítulo 15

Categorias e Centros de Custo

Gerenciamento das classificações de receitas e despesas

Categorias e Centros de Custo são as estruturas de classificação usadas em todos os módulos de lançamento. Uma boa configuração dessas estruturas torna os relatórios muito mais informativos e precisos.

Categorias

Categorias classificam receitas e despesas por natureza. Exemplos: Aluguel, Salários, Serviços, Vendas, Marketing, Energia Elétrica.

Como criar uma categoria

  1. Acesse Categorias na sidebar (geralmente no rodapé do menu ou em Configurações).
  2. Clique em + Nova Categoria.
  3. Informe o Nome da categoria.
  4. Selecione o Tipo: Entrada (E), Saída (S) ou Ambos.
  5. Escolha uma Cor para identificação visual nos gráficos.
  6. Clique em Salvar.
CampoDescriçãoObrigatório
NomeNome da categoria (ex.: "Energia Elétrica")Sim
TipoE = só entradas; S = só saídas; Ambos = para os dois tiposSim
CorCor hexadecimal para identificação nos gráficosNão

Como excluir uma categoria

Clique no ícone ✕ ao lado da categoria. Categorias em uso por lançamentos não podem ser excluídas — primeiro reclassifique os lançamentos.

Excluir uma categoria remove-a das opções de todos os formulários. Lançamentos já categorizados mantêm o nome registrado, mas a categoria fica desvinculada nos relatórios.

Centros de Custo

Representam departamentos, filiais ou áreas de negócio responsáveis pelos gastos. Exemplos: Administrativo, Comercial, TI, Produção, RH.

Como criar um Centro de Custo

  1. Na mesma tela de categorias, acesse a aba Centros de Custo.
  2. Clique em + Novo Centro.
  3. Informe o Nome do centro (ex.: "Departamento Comercial").
  4. Clique em Salvar.
Defina os Centros de Custo antes de iniciar os lançamentos de despesas para garantir relatórios precisos por área desde o início.

Capítulo 18

Backup e Restore

Proteção, portabilidade e recuperação dos dados do sistema

Como o sistema armazena todos os dados no localStorage do navegador, é fundamental realizar backups periódicos. O localStorage pode ser apagado se o usuário limpar os dados do navegador, formatar o disco, ou ao tentar usar o sistema em outro computador.

O localStorage NÃO é um sistema de armazenamento permanente. Dados podem ser perdidos se o cache do navegador for limpo. Faça backup regularmente — recomendamos semanalmente.

Alerta de backup no Dashboard

O sistema exibe automaticamente um alerta no Dashboard quando detecta que o último backup foi realizado há mais de 7 dias. Não ignore esse alerta.

Exportar JSON (Backup Completo)

  1. Acesse o módulo de Backup na sidebar.
  2. Clique em ⬇ Exportar JSON.
  3. Um arquivo backup-gestao-financeira-YYYY-MM-DD.json será baixado.
  4. Salve em local seguro: HD externo, Google Drive, OneDrive etc.

Exportar CSV (por tabela)

  1. Clique em ⬇ Exportar CSV.
  2. O sistema gera múltiplos arquivos CSV, um para cada tabela de dados.
  3. Os arquivos podem ser abertos diretamente no Excel ou Google Sheets.

Restaurar de JSON

  1. No módulo de Backup, clique em ↑ Restaurar de JSON.
  2. Localize o arquivo de backup .json salvo anteriormente.
  3. Confirme a restauração na janela de aviso.
  4. Todos os dados atuais serão substituídos pelos dados do backup.
  5. O sistema recarregará automaticamente com os dados restaurados.
A restauração via JSON substitui todos os dados atuais. Esta ação não pode ser desfeita. Se quiser preservar o estado atual, faça um backup antes de restaurar.

Boas práticas de backup

  • Faça backup sempre antes de operações em lote (importação OFX, reset de dados)
  • Mantenha os arquivos JSON em pelo menos 2 locais diferentes
  • Nomeie os arquivos com a data para facilitar identificação
  • Para migrar dados entre computadores, use o backup JSON — ele contém 100% dos dados
  • Os arquivos CSV são úteis para análise em planilhas, mas não podem ser usados para restaurar o sistema
Glossário

Termos e Definições

Referência de termos técnicos utilizados no sistema e neste manual
Aging
Relatório de envelhecimento de contas a receber ou a pagar que classifica os valores pendentes em faixas de vencimento (1–30, 31–60, 61–90, +90 dias). Permite identificar contas mais antigas e em maior risco de inadimplência ou atraso.
Balancete
Demonstrativo contábil que lista as contas do Plano de Contas com os totais a Débito, a Crédito e o Saldo para um determinado período. Serve para verificar o equilíbrio das partidas dobradas e é base para outros demonstrativos contábeis.
Centro de Custo
Unidade organizacional (departamento, filial, projeto) utilizada para classificar e controlar despesas por área responsável. Permite analisar o custo de cada parte da empresa separadamente, facilitando decisões de gestão.
Conciliação Bancária
Processo de comparação e cruzamento entre os lançamentos registrados no sistema e as transações do extrato bancário, garantindo que ambos sejam idênticos e identificando eventuais divergências, erros ou transações não registradas.
CP — Contas a Pagar
Módulo e conceito de controle das obrigações financeiras da empresa com terceiros (fornecedores, prestadores, impostos etc.) que ainda não foram quitadas. Representa o passivo circulante operacional.
CR — Contas a Receber
Módulo e conceito de controle dos direitos financeiros da empresa sobre clientes (valores devidos por vendas ou serviços prestados e ainda não recebidos). Representa o ativo circulante operacional.
DRE — Demonstração do Resultado do Exercício
Demonstrativo financeiro que apresenta as receitas, despesas e o resultado líquido de um período. A versão gerencial simplificada no sistema mostra receita bruta, despesas por categoria, resultado operacional e margem percentual.
localStorage
Tecnologia do navegador web que permite armazenar dados localmente no computador do usuário, sem necessidade de servidor ou banco de dados externo. Os dados persistem após o fechamento do navegador, mas são vinculados ao navegador e computador específicos — não sincronizam automaticamente.
OFX — Open Financial Exchange
Formato de arquivo padronizado para intercâmbio de dados financeiros, amplamente utilizado por bancos brasileiros para exportação de extratos. O arquivo .ofx contém as transações bancárias em formato estruturado que pode ser lido e importado pelo sistema.
Plano de Contas
Lista estruturada e hierárquica de todas as contas contábeis utilizadas por uma empresa para registrar suas operações financeiras. Cada conta possui um código numérico, nome, natureza (devedora ou credora) e grupo (ativo, passivo, receita, despesa).
